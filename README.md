# ملفات وبيانات محفظة د. م. عبدالمجيد البطاطي
## Abdulmajeed Albatati Portfolio Data & Assets

تم استخراج ونسخ كافة محتويات وبيانات الموقع القديم ([asalbatati.net](https://www.asalbatati.net)) وتجهيزها لبناء المحفظة الجديدة (Portfolio).

---

### هيكل المجلدات (`albatati-portfolio`)

```
albatati-portfolio/
├── extracted_data/
│   ├── portfolio_master_data.json       # ملف JSON شامل لكافة بيانات الموقع (جاهز للاستيراد المباشر في React/Next.js/Astro)
│   ├── contact.json                     # بيانات التواصل، المؤهلات والمسيرة
│   │
│   ├── cv/                              # السيرة الذاتية
│   │   ├── Abdulmajeed_Albatati_CV_Arabic.pdf   # السيرة الذاتية PDF عربي
│   │   ├── Abdulmajeed_Albatati_CV_English.pdf  # السيرة الذاتية PDF إنجليزي
│   │   ├── cv_arabic.txt                        # نص السيرة الذاتية عربي
│   │   ├── cv_english.txt                       # نص السيرة الذاتية إنجليزي
│   │   └── scans/                               # صور صفحات السيرة الذاتية (عربي وإنجليزي)
│   │
│   ├── books/                           # الكتب والأبحاث (11 بحث وكتاب)
│   │   ├── books.json                   # بيانات تفصيلية لجميع الكتب والأبحاث
│   │   ├── books.md                     # تقرير markdown كامل بالأبحاث
│   │   ├── covers/                      # صور أغلفة جميع الكتب والأبحاث
│   │   └── pdfs/                        # جميع ملفات الـ PDF الأصلية للكتب والأبحاث
│   │
│   ├── articles/                        # المقالات (8 مقالات كاملة)
│   │   ├── articles.json                # بيانات المقالات
│   │   ├── images/                      # صور المقالات
│   │   └── markdown/                    # نصوص المقالات كاملة بصيغة Markdown
│   │
│   ├── subjects/                        # مواضيع أخرى (8 مواضيع وقضايا رأي)
│   │   ├── subjects.json
│   │   ├── images/
│   │   └── markdown/
│   │
│   ├── events_and_media/                # الفعاليات، المشاريع وألبومات الصور (21 عنصر)
│   │   ├── events.json                  # تفاصيل المشاريع وتغطيات الصحف والزيارات
│   │   └── images/                      # مئات الصور الميدانية والألبومات (مشروع السامر، أم الخير، وغيرها)
│   │
│   └── brand_assets/                    # الشعارات والأيقونات وصور الموقع
│
└── www.asalbatati.net/                  # نسخة طبق الأصل من الموقع القديم (Raw Mirror)
```

### ملخص الإحصائيات
* **إجمالي الملفات:** 396+ ملف
* **الكتب والأبحاث:** 11 كتاب وبحث مع ملفات الـ PDF الخاصة بها
* **المقالات ومواضيع الرأي:** 16 مقال وموضوع متكامل النصوص
* **الألبومات والمشاريع الميدانية:** 21 فعالية/مشروع مع أكثر من 250 صورة عالية الدقة
* **السيرة الذاتية:** متوفرة باللغتين العربية والإنجليزية (نص + PDF + صور)
